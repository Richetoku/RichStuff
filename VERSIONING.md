# Versioning policy

- RichStuff and AllTheOres remain in pre-release `0.0.x` versions until the first public release.
- The current suite version is `0.0.5`.
- Ordinary fixes and feature additions increment the patch number by `0.0.1`.
- A complete rewrite may increment the minor pre-release number by `0.1.0`.
- Version `1.0.0` is reserved for the first release-ready build and must not be used before release.
- Both sibling mods use the same suite version unless explicitly split later.
