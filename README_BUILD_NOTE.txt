RichStuff 0.0.5 contains Rikumi Mita as a native RichStuff entity, model, renderer, owner-only menu, outfit system, and present block.

Delete an older source folder before extraction when possible. The root launcher also runs tools/clean_legacy_sources.py to remove stale pre-native Rikumi classes before Gradle compiles.

RichStuff requires the sibling AllTheOres 0.0.5 project plus the runtime dependencies declared in neoforge.mods.toml.
